Core Philosophy

这些技能为何存在？

我构建这些技能，是为了修复我在 Claude Code、Codex 及其他编码 Agent 上看到的 4 大常见失败模式。

#1：Agent 没做我想要的东西

目标对齐
“没有人能确切知道自己想要什么。” David Thomas & Andrew Hunt，《程序员修炼之道》（The Pragmatic Programmer）

问题根源：软件开发中最常见的失败模式就是目标不一致。你以为开发者知道你想要什么，交付时才发现南辕北辙。在 AI 时代也一样，你和 Agent 之间存在沟通鸿沟。解决办法是一场严拷式会话（Grilling Session）——让 Agent 就你正在构建的东西向你提出详细问题。

修复方案：严拷会话与边界挖掘

在动手前与 Agent 彻底达成一致，深入思考正在做的改动。

/grill-with-docs ↗ /grill-me ↗ /to-questionnaire ↗

#2：Agent 太啰嗦了

领域建模
“有了通用语言，开发者之间的对话与代码的表达全都源自同一个领域模型。” Eric Evans，《领域驱动设计》（Domain-Driven-Design）

问题根源：Agent 通常被随手丢进一个项目，然后被要求边走边弄清楚那些行话。于是它们用 20 个词才能说清 1 个词就能讲明白的事。修复方法是沉淀一份帮助 Agent 解码项目行话的 CONTEXT.md 文档，建立统一领域模型。

修复方案：沉淀 CONTEXT.md 领域通用语言

统一命名、快速导航代码库、大幅降低思考 Token 消耗。

domain-modeling ↗ /grill-with-docs ↗ /wait-what ↗

#3：代码跑不通

质量闭环
“永远采取小而刻意的步骤。反馈的速率就是你的速度上限。绝不要接手过于庞大的任务。” David Thomas & Andrew Hunt，《程序员修炼之道》

问题根源：假设你和 Agent 在要构建什么上达成了共识，当 Agent 仍然写出一堆垃圾时会发生什么？没有关于它产出的代码实际运行情况的反馈，Agent 就是在盲飞。你需要常规的反馈回路组合：静态类型、浏览器访问以及自动化测试。

修复方案：红-绿-重构 (TDD) 与纪律性调试

先写失败测试再写实现，配合阶段把关调试循环（变红 ➔ 最小化 ➔ 假设 ➔ 插桩 ➔ 修复）。

/tdd (红绿重构) ↗ /diagnosing-bugs ↗ /code-review ↗

#4：我们造了一坨烂泥

架构深模块
“最好的模块是深的。它们通过一个简单的接口，就能访问大量功能。” John Ousterhout，《软件设计的哲学》（A Philosophy Of Software Design）

问题根源：大多数用 Agent 构建的应用都复杂且难以改动。因为 Agent 能极大加速编码，它们也同时加速了软件的熵增。代码库以空前的速率变得越来越复杂。修复方法是对 AI 驱动开发采取一种激进的新思路：关心代码的设计。

修复方案：深模块设计与定期架构扫描

定期扫描代码库寻找「加深（Deepening）」机会，输出可视化 HTML 报告并严拷重构。

/improve-codebase-architecture ↗ codebase-design ↗ /to-spec ↗
案例对比：来自真实项目 course-video-manager 的 CONTEXT.md 落地效果
Token 节省 80% · 消除歧义
改前（缺乏通用语言 · 啰嗦易失真）
"当课程里某个章节中的一课被'实体化'（即被赋予了文件系统中的某个位置）时，会出问题。"

⚠️ 痛点：Agent 需要阅读长篇解释，在长会话中极易发生概念漂移和逻辑理解偏差。

改后（建立通用语言 · 精确直达）
"实体化级联（materialization cascade）出问题了。"

✅ 收益：变量与架构命名保持一致，Agent 导航代码库更精准，思考消耗更少 Token。

Quick Setup

安装（30 秒搞定）

两种进入方式，两种理念：Claude Code 插件 作为受管理的只读包自动更新；skills.sh 把可编辑源码写入项目据为己有。

位于 Claude Code 官方市场，作为一个受管理的只读包安装。我会发布更新它就更新——你是在订阅，而不是复刻：

claude plugins install mattpocock-skills

或者在 Claude Code 会话内直接执行：/plugin install mattpocock-skills

使用 skills.sh 安装器，选择你想要的技能，以及要把它们安装到哪些编码 Agent 上：

npx skills@latest add mattpocock/skills

💡 提示：安装器允许你选择要取用哪些技能——务必把 setup-matt-pocock-skills 包含在内。

用同一个安装器，它会把这些技能作为你拥有且可编辑的普通文件写入你的仓库：

npx skills@latest add mattpocock/skills
npx skills update
